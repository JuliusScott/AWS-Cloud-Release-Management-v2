Continuous Integration

Source changes from GitHub enter CodePipeline and are processed by AWS CodeBuild.

Container Build

CodeBuild packages the application into a Docker image and pushes the image to Amazon ECR.

Development

The container is deployed to Amazon ECS using AWS Fargate for development validation.

Production Gate

Production deployment requires manual approval after the development release has been validated.
